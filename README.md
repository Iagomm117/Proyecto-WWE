# Proyecto-WWE

Primero de todo se requiere de tener docker, para probar estar version y netbeans instalado. Para poder ejecutar el proyecto se tiene que ir al terminal, entrar en la carpeta de este proyecto en el ordenador local, donde se encuentra el docker-compose.yaml y hacer el comando docker-compose up -d. Hecho esto, se abre netbeans y se abre el proyecto y se lanza el programa. Para poder acceder se puede crear una cuenta o usar la cuenta con usuario test y contraseña abc123.
